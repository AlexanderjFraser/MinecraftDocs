# Lectures

The video series will be an *ordering* over the system pages, which are
the stable content. The order is drafted in pass 3 — restructuring and
lecture order are the same judgement — and confirmed by the owner in
pass 5, after reading every part with the decompile open. Until then the
parts in the sidebar are the reading order: each part only assumes the
ones before it.

| pass | what happens | status |
|---|---|---|
| 1 | every system page drafted from the decompile, names verified, published | done |
| 2 | completeness and accuracy: every claim fact-checked against the decompile, gaps filled, pages split and added | in progress |
| 3 | restructuring: each part takes the shape of the system it explains; the lecture order is drafted here | not started |
| 4 | polish: wording, consistency, cuts | not started |
| 5+ | the owner reads, asks, corrects; the lecture order is confirmed; then voice, cuts and recording | not started |

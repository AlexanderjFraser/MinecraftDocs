# Maps

Generated views of the 26.2 decompile, regenerated each version with
`python tools/map_source.py`. They are the "where is everything" answer a
newcomer wants before any system page makes sense.

- [Packages](packages.md) — classes and lines per package, and how many are client-only.
- [Biggest classes](biggest.md) — where the mass is.
- [Hierarchy](hierarchy.md) — the widest inheritance trees.
- [Fan-in](fanin.md) — the most-imported classes: the hubs.
